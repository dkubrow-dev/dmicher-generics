# Общее приветствие

Generics отправляет при загрузке личное сообщение от общего Информатора. В списке находятся все активные пакеты, чьи ID начинаются с `dmicher`: название и версия берутся из установленного пакета. Доступность справки определяется объявленным `openHelp` в локальном реестре; незарегистрированный модуль остаётся в списке. Для самого Generics открывается его общая справка.

Мировая настройка `showWelcome` («Приветствие модулей dmicher» / «dmicher module welcome») доступна мастеру бесплатно в штатных настройках Foundry. Она не выключает Информатора или сообщения других модулей. В подсказке есть переход на страницу `welcome`, раздел `showWelcome`. Содержание карточки и её личные кнопки отображаются на языке текущего клиента, русском или английском.

Каждый клиент при `ready` записывает новую случайную метку `flags.dmicher-generics.welcomeSession` только в собственный User. Избранный активный полный мастер обрабатывает обновления документов и существующих подключённых участников. Ключ `welcome:<userId>:<session>` сверяется с историей сообщений: повторный hook и переподключение мастера не повторяют приветствие уже находящемуся в мире игроку. Новая загрузка игрока создаёт новую метку. Если полного мастера нет, доставка ждёт его подключения. Несуществующий, отключённый или технический адресат не получает сообщение.

Сокетное поле `requesterId` для приветствия не используется. В `updateUser` учитывается автор изменения, предоставленный Foundry; отправитель карточки всё равно перечитывает активность, роль и метку пользователя. Текст о лицензии определяется только ответом optional Premium provider через `generics.premium.getAccessStatus(moduleId)` после ограниченного ожидания `waitUntilReady()`. Generics не читает ключи, токены, claims или API модуля Premium напрямую и не принимает лицензионных решений.

Кнопки справки и настроек — локальные действия, привязанные к существующему видимому документу через общий `chat.bindActions`. Ссылку подписки получает только мастер бесплатного режима. Удаление старого приветствия вручную удаляет и его ключ из истории; очередная проверка той же загрузки может создать его вновь. Приветствие не является глобальной сетевой транзакцией; избранный ГМ ограничивает исполнение, а Foundry остаётся владельцем прав записи документов.
