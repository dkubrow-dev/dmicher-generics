# dmicher Generics 1.0.0

Начальное выделение общей инфраструктуры из Spotlight; локальная сборка для разработки комплекта.

- Общие палитры и элементы оформления окон применяются только к `.dmicher-window`.
- Темами управляет каждый модуль отдельно; пользовательские настройки Spotlight сохраняются.
- Вынесены повторное открытие одиночного окна, ожидание его жизненного цикла, получение DOM-элемента, порядок настроек, HTML-экранирование и последовательная очередь задач.
- Добавлен публичный API 1 и реестр API модулей `dmicher-*` с явными версиями и возможностями.
- В `generics.chat` выделены технические User/Actor, восстановление стабильных ID, минимальные права и освобождаемый запрос синхронизации избранному GM. Каждая личность принадлежит своему потребителю; существующие НПС для диалогов не изменяются. Старые объекты Spotlight получают общий маркер с сохранением прежних флагов и настройки.
- Общие сообщения поддерживают явную публичную или частную аудиторию, групповой whisper и отдельные копии, логические ключи и ID документов, поиск, изменение содержимого и удаление с проверкой прав Foundry. Пустой список частных получателей ничего не отправляет; частичный сбой компенсируется с отчётом об оставшихся копиях.
- Общая привязка кнопок и форм проверяет актуальную видимость содержимого и разрешение потребителя, освобождает обработчики и подавляет повторное нажатие занятой кнопки. Изображения и видео получили общую конечную цепочку резервных источников. Тексты, настройки и предметные команды остаются у потребителя.
- Манифест объявляет `socket: true` для узкой команды синхронизации технических личностей; пассивный импорт API не создаёт документы и не подписывается на сокет. Подробные контракты и примеры находятся в [документации чата](docs/chat-api.md).
- Добавлен необязательный мост `generics.premium` для версионируемых чистых синхронных методов. Premium поставляет реализации, а потребитель сохраняет бесплатные методы и собственные настройки; лицензионная логика остаётся в Premium.
- Регистрация, уведомления, предел ожидания готовности внутри одного потребителя и освобождение проверены отдельно; сроки разных модулей независимы. Доступ сверяется при каждом вызове, ошибка расширения одной цели не отключает другую. Прямое подключение Premium к Spotlight заменено общим контрактом.
- KISS и SOLID закрепляют границы: Generics содержит технические договоры и оформление, продуктовые и премиальные правила принадлежат их владельцам.
- Нет зависимостей от игровой системы, Premium и сервера лицензий. Поддерживаются Foundry VTT 13/14.
- Добавлены самостоятельные тесты, воспроизводимая ZIP-сборка и проверяемый локальный деплой.
- Манифест указывает точную версию релиза1.0.0; отдельный артефакт, ZIP и исходники сверяются побайтно. Сборка отклоняет изменяемые или несогласованные ссылки.

API 1 is the initial shared contract for dmicher modules. Per-consumer themes preserve existing Spotlight settings. Window helpers and local API discovery do not implement gameplay, network authority or licensing. This is a local development build, not confirmation of a public GitHub release.
