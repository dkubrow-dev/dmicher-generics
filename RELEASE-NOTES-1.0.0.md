# dmicher 🧰 Generics 1.0.0

Начальное выделение общей инфраструктуры из Spotlight; локальная сборка для разработки комплекта.

- Потребитель справки может исключить значки вопроса из последовательной навигации Tab, сохранив подсказки и открытие мышью. Ширма включает это поведение; остальные модули сохраняют прежнюю навигацию.
- В таблицах параметров значок справки располагается рядом с названием параметра в заголовке строки. Поле значения сохраняет компактную высоту; явные подписи и поведение кнопок остаются приоритетными.

- Общие палитры и элементы оформления окон применяются только к `.dmicher-window`.
- Внешним видом всех окон dmicher управляет одна клиентская настройка Generics: встроенные тёмный и светлый стили. Прежний явно сохранённый выбор потребителя переносится при первом запуске; уже выбранная общая тема не перезаписывается.
- В общих настройках добавлены прилипание к экрану и окнам dmicher, выравнивание углов и центров. Правая кнопка переносит весь каскад прилипших окон, левая отделяет выбранное окно. Связи учитываются по постоянным ID; `appearance.getWindowLayout()` отдаёт снимок окон и связей для дальнейшей работы с рабочими местами. Панели и программное восстановление расположения не создают прилипание.
- Premium поставляет реальную реализацию слоя пользовательского CSS поверх встроенного стиля. Файл до 64 КиБ сохраняется в Generics; при отзыве доступа слой отключается без удаления файла и возвращается после восстановления доступа. Требуется доступ именно к Generics.
- Общий интерфейс справки содержит раскрывающееся дерево, изменяемую ширину левого меню и нижние страницы автора, благодарностей и «Модули dmicher». Содержимое всех страниц RU/EN хранится в соответствующем модуле. Неиспользуемый переход старого ID `premium` в `modules` удалён: потребители явно объявляют актуальные страницы. Общие значки вопроса показывают подсказку и открывают нужную страницу и раздел. Вопросики у кнопок лежат поверх левого верхнего угла, не меняют размеры U/I/B и не нажимают саму кнопку; подчёркивание убрано.
- «Сохранить» в оформлении применяет значения и оставляет форму открытой, сохраняя новые правки, сделанные во время ожидания записи.
- `generics.components` добавляет синхронные HEX/палитру и контекстные импорт/экспорт JSON. Правила проверки объекта, права и запись остаются у потребителя.
- Вынесены повторное открытие одиночного окна, ожидание его жизненного цикла, получение DOM-элемента, порядок настроек, HTML-экранирование и последовательная очередь задач.
- Добавлен публичный API 1 и реестр API модулей `dmicher-*` с явными версиями и возможностями.
- Generics создаёт и поддерживает общего «Информатора»: технического пользователя и актёра в `dmicher modules/generic`. Старые документы Spotlight не присваиваются и не мигрируют. Spotlight использует общий сервис для новых сообщений, сохраняя собственные правила, аудиторию и историю карточек. Настоящие НПС для диалогов не изменяются.
- Общее приветствие отправляет Информатор. Оно перечисляет все включённые модули dmicher с названиями и версиями, открывает их справку и настройки Foundry. Текст учитывает роль получателя и подтверждённый Premium-доступ. Бесплатная настройка приветствия находится в Generics; её отключение не отключает сообщения других модулей.
- Каждый участник получает частное приветствие при загрузке. Позднее подключение поддержано; перезагрузка мастера не повторяет приветствия остальных участников. Содержимое локализуется на русском и английском.
- Исправлен экспорт JSON: сохраняется тип `application/json;charset=utf-8` и расширение `.json`, а нажатие на ссылку скачивания больше не перехватывает общий обработчик ссылок Foundry.
- Общие сообщения поддерживают явную публичную или частную аудиторию, групповой whisper и отдельные копии, логические ключи и ID документов, поиск, изменение содержимого и удаление с проверкой прав Foundry. Пустой список частных получателей ничего не отправляет; частичный сбой компенсируется с отчётом об оставшихся копиях.
- Общая привязка кнопок и форм проверяет актуальную видимость содержимого и разрешение потребителя, освобождает обработчики и подавляет повторное нажатие занятой кнопки. Изображения и видео получили общую конечную цепочку резервных источников. Тексты, настройки и предметные команды остаются у потребителя.
- Манифест объявляет `socket: true` для узкой команды синхронизации технических личностей; пассивный импорт API не создаёт документы и не подписывается на сокет. Подробные контракты и примеры находятся в [документации чата](docs/chat-api.md).
- Добавлен необязательный мост `generics.premium` для версионируемых чистых синхронных методов. Premium поставляет реализации, а потребитель сохраняет бесплатные методы и собственные настройки; лицензионная логика остаётся в Premium.
- Регистрация, уведомления, предел ожидания готовности внутри одного потребителя и освобождение проверены отдельно; сроки разных модулей независимы. Доступ сверяется при каждом вызове, ошибка расширения одной цели не отключает другую. Прямое подключение Premium к Spotlight заменено общим контрактом.
- KISS и SOLID закрепляют границы: Generics содержит технические договоры и оформление, продуктовые и премиальные правила принадлежат их владельцам.
- Нет зависимостей от игровой системы, Premium и сервера лицензий. Поддерживаются Foundry VTT 13/14.
- Добавлены самостоятельные тесты, воспроизводимая ZIP-сборка и проверяемый локальный деплой.
- Манифест указывает точную версию релиза1.0.0; отдельный артефакт, ZIP и исходники сверяются побайтно. Сборка отклоняет изменяемые или несогласованные ссылки.

API 1 is the initial shared contract for dmicher modules. Per-consumer themes preserve existing Spotlight settings. Window helpers and local API discovery do not implement gameplay, network authority or licensing. This is a local development build, not confirmation of a public GitHub release.
